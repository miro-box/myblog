三、以后添加图片

核心流程：只处理新图、只上传新图、最后提交清单。 脚本和 rclone 都是增量的，已有的会自动跳过，所以每次都是同样四步。

把新图放进原图文件夹（和第一次用的 -Src 是同一个）。
重新运行脚本：
powershell
powershell -ExecutionPolicy Bypass -File .\build-gallery.ps1 -Src "D:\blog-assets\waifus"

已处理的图（按内容哈希识别）会跳过，只处理新增的，并更新 data\waifus.json。

上传新增的文件，命令和上面完全一样，rclone copy 会自动跳过已存在的，只传新的。
最后提交清单：
powershell
git add data/waifus.json
git commit -m "add gallery images"
git push

顺序很重要：先传图，再推送清单。反过来的话，网站上线后清单里有图、桶里还没有，会短暂出现裂图。


原图文件夹路径:D:\blog-assets\waifus
